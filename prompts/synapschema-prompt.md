# 🗺️synapschema生成プロンプト

このプロンプトは、指定したテーマ（例：「タンパク質」「量子力学」「Web3」など）に基づいて、UI/UXおよびデータ構造が最適化された「完全な1ファイルで動くHTML（React + Tailwind CSS）」をAIに生成させるための指示文テンプレートです。

---

## 📝 使い方
1. 下記の **「Prompt」** セクションのテキストをコピーします。
2. **`主題：「〇〇」`** の `〇〇` 部分を、作成したいテーマに書き換えます（例：`主題：「タンパク質」`）。
3. ChatGPT, Claude, Gemini などのLLMに貼り付けて実行します。

---

## 🤖 Prompt

```text
あなたはUI/UXデザインおよびデータ構造化のプロフェッショナルです。
以下の要件および構造に従い、主題を「〇〇」に変更したインタラクティブな知識図鑑（タッチマップ）の完全なHTMLコードを作成してください。

---

### 1. テーマ
主題：「〇〇」

---

### 2. データ構造の更新ルール

テーマ「〇〇」の内容に合わせて、テキストおよびデータ配列（CATEGORIES, CONCEPTS, TIMELINE）を全面書き換えしてください。

#### ① CATEGORIES（大カテゴリ：4〜6個程度）
「〇〇」を理解・探索するための主要な分類・軸を設定し、名前（name）と概要（description）を作成してください。

#### ② CONCEPTS（構成要素・概念データ：8〜12個程度）
各概念には以下の構造を持たせてください：
- id: ユニークな英数キー（例: concept1）
- cat: 所属する CATEGORIES の id
- title: 概念/要素の名称
- headline: 一行で伝える核心のキャッチコピー
- summary: 詳細な解説文（2〜3文）
- era: 補足タグ（例: フェーズ、難易度、分類、対象時期など）
- perspectives: 主題「〇〇」の性質に合わせて、以下の5つの視点（またはそれに適した見出し名）でデータを整理してください。
  1. 構成要素・関係者（人物、モジュール、関連データなど）
  2. 前提・段階・コンテキスト（前提知識、適用フェーズ、背景など）
  3. 因果・メカニズム（「なぜ？」「どう機能する？」のQ&A形式）
  4. 関連領域・適用先（場所、環境、プラットフォーム、カテゴリタグなど）
  5. プロセス・手順・歴史（時系列、ロードマップ、実行手順など）
  ※ 他の概念へハイパーリンク接続できる項目には、対応する targetId を正確に付与してください。

#### ③ TIMELINE / ROADMAP（全体マップ・流れ：6〜10個程度）
「〇〇」の「全体像」「ロードマップ」「実行プロセス」「歴史」などの流れを表すステップ/年表を作成し、クリック時に該当する conceptId へジャンプできるように設定してください。UI上の表記もテーマに合わせて（例:「📅 年表」→「🗺️ 全体ロードマップ」など）適切に変更してください。

---

### 3. 出力条件
- React / JSX / HTML / Tailwind CSS のプログラム構造や画面遷移ロジックはそのまま維持してください。
- コードブロック内に省略（`// 以下省略` など）を含めず、そのまま `.html` ファイルとして保存すればブラウザで直接動作する「完全な1つのHTMLコード」を出力してください。
