# 🗺️synapschema（シナプスキーマ）生成プロンプト

このプロンプトは、指定したテーマ（例：「タンパク質」「歴史」「元素」など）に基づいて、UI/UXおよびデータ構造が最適化された「完全な1ファイルで動くHTML（React + Tailwind CSS）」をAIに生成させるための指示文テンプレートです。

## 注意

生成された内容にはハルシネーションが含まれる可能性があります。
重要な情報については、必ず信頼できる情報源で確認してください。

---

## 📝 使い方
1. 下記の **「Prompt」** セクションのテキストをコピーします。
2. **`主題：「〇〇」`** の `〇〇` 部分を、作成したいテーマに書き換えます（例：`主題：「タンパク質」`）。
3. **本リポジトリ内examplesフォルダにある `protein.html` ファイルをダウンロードし、AIへのプロンプト送信時に一緒に添付**してください。
4. ChatGPT, Claude, Gemini などのLLMに貼り付けて実行します。

---

## 🤖 Prompt

```text
# 🎭 UI/UX & Data Structuring Specialist Prompt: Interactive Touch Map Template

## 概要 (Overview)
あなたはUI/UXデザインおよびデータ構造化のプロフェッショナルです。
以下に提供する雛形（テンプレート）HTMLコードをベースに、主題を「〇〇」に変更したインタラクティブな知識図鑑（タッチマップ）の完全なHTMLコードを作成してください。

---

## 1. テーマ (Theme)
* **主題**: 「〇〇」

---

## 2. データ構造の更新ルール (Data Structure Rules)
テーマ「〇〇」の内容に合わせて、テキストおよびデータ配列（`CATEGORIES`, `CONCEPTS`, `TIMELINE`）を全面書き換えてください。

### ① CATEGORIES（大カテゴリ）
「〇〇」を理解・探索するための主要な分類・軸を設定し、名前（`name`）と概要（`description`）を作成してください。（※個数はテーマによって調整）

### ② CONCEPTS（構成要素・概念データ）
個数はテーマによって調整し、各概念には以下のプロパティを持たせてください：

* **`id`**: ユニークな英数キー（例: `concept1`）
* **`cat`**: 所属する `CATEGORIES` の id
* **`title`**: 概念/要素の名称
* **`headline`**: 一行で伝える核心のキャッチコピー
* **`summary`**: 詳細な解説文（2〜3文）
* **`era`**: 補足タグ（例: フェーズ、難易度、分類、対象時期など）
* **`perspectives`**: 主題「〇〇」の性質に合わせて、多角的な視点（項目数や見出し名はテーマに合わせて適切に調整）でデータを整理してください。
  * *記述例*: 構成要素・関係者、前提・段階、因果・メカニズム（Q&A形式）、関連領域・適用先、プロセス・手順・歴史 など
  * **注意**: 他の概念へハイパーリンク接続できる項目には、対応する `targetId` を正確に付与してください。

### ③ TIMELINE / ROADMAP（全体マップ・流れ）
「〇〇」の「全体像」「ロードマップ」「実行プロセス」「歴史」などの流れを表すステップ/年表を作成してください（※個数はテーマによって調整）。
* 各ステップをクリックした際、該当する `conceptId` へジャンプできるように設定してください。
* UI上の表記もテーマに合わせて適切に変更してください（例:「📅 年表」→「🗺️ 全体ロードマップ」など）。

---

## 3. 出力条件 (Output Requirements)
1. **ロジックの維持**: React / JSX / Tailwind CSS のプログラム構造や画面遷移ロジックはそのまま維持すること。
2. **完全な単一ファイル**: コードブロック内に省略（`// 以下省略` など）を含めず、そのまま `.html` ファイルとして保存すればブラウザで動く「完全な1つのHTMLコード」を出力すること。

---

## 4. 雛形HTMLコード (Base Template)

protein.htmlを添付します
